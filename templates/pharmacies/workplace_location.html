This estimate is not accepted as verified GPS when accuracy is too weak. Only use the manual option after checking the exact branch entrance/premises on the map; the saved source will be marked Manual.

The system accepts automatic GPS readings only when accuracy is 250m or better; for attendance, 50m or better is ideal. If the signal stays weak, the estimate is drawn on the map so you can pin the exact premises (saved as Manual). Your browser must allow precise location access.

How to get a better GPS signal
  1. Go outside, or stand next to an open door or window, away from tall buildings and metal roofs.
  2. Device Settings → Location: turn it On. On Android, enable Google Location Accuracy / Improve Location Accuracy; on iPhone/iPad, allow Precise Location for the browser.
  3. When the browser asks, choose Precise location (not Approximate).
  4. Avoid in-app browsers. Use an up-to-date Chrome, Safari, Edge, or Firefox. Keep Wi-Fi enabled where available; desktop computers may estimate location from Wi-Fi and may not have a GPS sensor.
  5. Wait 30–60 seconds after switching location on, then tap Capture again.
Still no good signal? Enter coordinates manually

Open Google Maps, press and hold on the exact spot of the branch, then copy the coordinates (or paste the Google Maps link) here.

Manual points are recorded as Manual (no accuracy value) and stay visible in the branch audit trail. Prefer device GPS whenever possible.

Recommended setup

  1. 1. Stand inside the branch.
  2. 2. Use a supported browser with location permission enabled. For computers without a GPS sensor, verify the branch pin manually.
  3. 3. Capture the GPS point.
  4. 4. Confirm the reading and save.
  5. 5. Test one employee's Verify & Start Workday flow.

Important

Employee location is checked only when they verify attendance or presence. The system does not continuously track employees.

Do not use IP address as a replacement for GPS.
