Network logos for the mobile-money checkout
===========================================
Included (360x240 PNG, white background, cropped and centred):

  vodacom-mpesa.png     M-Pesa (Vodacom)
  airtel-money.png      Airtel Money
  mixx-by-yas.png       Mixx by Yas
  halopesa.png          HaloPesa (Halotel)

To replace one, overwrite the file keeping the same name. Any shape works (the checkout
fits it in a wide box). If a file is missing, a coloured badge with the initial is shown.
Use logos you are allowed to use (official brand / press kit).
