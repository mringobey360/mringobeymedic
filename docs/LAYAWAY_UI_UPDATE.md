# SmartPOS Layaway UI polish

The Layaway Management, Create Layaway, and Plan Detail templates were restyled to align with the authenticated SmartPOS workspace: shared theme tokens, teal accent, compact responsive panels, consistent form controls, clear status chips, mobile-friendly tables, readable empty states, and dark-theme support.

The UI improvements do not mean the Layaway feature is production-complete. Before using it for real customer funds, complete and test POS conflict detection, official Sale and cash-ledger posting, idempotent payment submission, receipt PDF generation, Africa's Talking SMS, manager-only resolution permissions, and end-to-end database migration checks.
