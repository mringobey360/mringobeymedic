# Receipt & Report Period Professional Update

## Receipt
- Standard 80mm thermal-roll width.
- Dynamic paper height calculated from actual receipt content.
- Short sales no longer produce a large blank paper area.
- Footer/copyright is positioned at the bottom of the receipt area.
- Branch logo is used when configured; system logo is the fallback.
- Professional printer-safe Helvetica core fonts are used.
- Low-contrast diagonal SmartPOS watermark remains behind the content.

## Advanced Reports
The main report period selector now uses a consistent professional dropdown with:
- Today
- Yesterday
- This Week
- Last Week
- Last 7 Days
- Last 30 Days
- This Month
- Last Month
- This Year
- Custom Date Range

Custom date inputs appear only when needed. Presets are translated into exact inclusive start/end dates before submission.
