# Receipt Branding Update

Each pharmacy branch can now store its own logo, email, registration/licence number, receipt header and receipt footer. If no pharmacy logo is uploaded, the default SmartPOS system logo is used. Receipts are branch-specific and include a professional watermark and the Mutech Apex Innovations copyright.

Reference design: compact pharmacy receipt with prominent pharmacy identity, official receipt title, customer/payment metadata, itemized sales, total, barcode and professional footer.
